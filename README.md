# Portafolio profesional

¡Bienvenido a mi portafolio!

Este proyecto nace como un espacio profesional donde puedo mostrar mis proyectos pasados y actuales, así como mis capacidades, conocimientos y logros a medida que continúo creciendo como desarrollador.

También busca ser un lugar abierto al feedback y a la comunicación, ya sea para colaboraciones, consultas, dudas o simplemente para conectar.

## ¿Qué encontrarás aquí?

Dentro del portafolio podrás encontrar información sobre mí, mis trabajos más recientes y algunos de mis proyectos anteriores.

También encontrarás enlaces a mis redes sociales y diferentes medios de contacto para facilitar la comunicación.

## ¿Cómo fue construido?

Para desarrollar este proyecto a partir del brief, decidí dividir la estructura de trabajo en secciones grandes y posteriormente en subsecciones más pequeñas.

Dentro de cada una seguí una metodología paso a paso basada en tres etapas:

**Reconocimiento → Entendimiento → Ejecución**

Primero analizo qué necesita la sección y cómo está construida en el diseño, después intento comprender la relación entre sus elementos y finalmente llevo esa estructura al código.

Este método me permitió avanzar de manera organizada y resolver los problemas uno por uno.

## Tecnologías y técnicas utilizadas

Este proyecto fue posible gracias a los conocimientos adquiridos previamente en:

- **HTML**, para construir la estructura y utilizar elementos semánticos.
- **CSS**, para desarrollar el diseño y la presentación visual de la página.
- **Flexbox**, para organizar y distribuir elementos dentro de diferentes secciones.
- **CSS Grid**, utilizado especialmente en la sección de proyectos.
- **Media queries**, para adaptar el sitio a resoluciones de escritorio, tablet y dispositivos móviles.
- **Pseudo-elementos**, utilizados para agregar elementos decorativos y efectos visuales.
- **Pseudo-clases**, utilizadas para agregar interacción a enlaces y otros elementos mediante estados como `:hover`.
- **Diseño responsivo**, buscando que cada elemento pueda adaptarse correctamente a diferentes tamaños de pantalla.

## Retos durante el desarrollo

No todo en el diseño y construcción de esta página fue sencillo.

Durante el proceso me encontré con distintos obstáculos, especialmente al interpretar el diseño de Figma, comprender las medidas y posiciones de los elementos y trasladar esas relaciones correctamente al código.

Este proyecto también representó mi primer contacto real con una página completamente responsiva. Comprender la lógica necesaria para que cada elemento pudiera adaptarse correctamente a diferentes resoluciones fue uno de los mayores retos.

La curva de aprendizaje fue grande, pero también fue superable y, finalmente, superada.

## Aprendizajes

Uno de los mayores aprendizajes de este proyecto fue comenzar a descubrir poco a poco mi propia manera de trabajar y mis métodos para implementar las tecnologías que estoy aprendiendo.

También pude desarrollar un mejor entendimiento general de CSS. Conceptos como Flexbox, Grid, diseño responsivo, media queries y la relación entre los diferentes elementos de una página comienzan a sentirse cada vez más familiares.

Más allá de completar el proyecto, siento que empiezo a construir una metodología propia para analizar problemas y llevar una idea desde el diseño hasta el código.
